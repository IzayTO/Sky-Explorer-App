PASOS PARA ISAI — CORRECCIÓN 4.1.1

QUÉ CONTIENE
Esta entrega actualiza tu Sky-Explorer-App actual. No es el proyecto entero.
Conserva los originales que no estén incluidos. El ZIP trae archivos completos,
sueltos; puedes reemplazarlos con tu método habitual en Archivos.

1. En ChatGPT toca SKY_EXPLORER_APP_CORRECCION_RENDIMIENTO.zip → Compartir →
   Guardar en Archivos. En Archivos toca el ZIP para descomprimirlo.
2. Si mantienes una carpeta original, sustituye únicamente los nombres de esta
   lista y añade shadow-atlas.js. No borres texturas, librerías ni otros archivos.
   También puedes subir estos archivos directamente al repositorio actual.
3. Abre Safari → github.com/IzayTO/Sky-Explorer-App → rama main → raíz.
   Toca Add file / Añadir archivo → Upload files / Subir archivos → selecciona
   TODOS los archivos sueltos de esta entrega, no el ZIP ni la carpeta.
4. Revisa los nombres → Commit changes / Confirmar cambios. Al coincidir
   ruta y nombre, GitHub reemplaza los anteriores; shadow-atlas.js se añade.
   Sube todo en una sola publicación. No necesitas eliminar primero los viejos.
   No hagas esto en IzayTO/Sky-Explorer.
5. Espera el despliegue verde de GitHub Pages en Actions. En Settings → Pages
   debe seguir main / (root). No tienes que compilar ni ejecutar Python o npm.
6. Si ya tienes la aplicación instalada, abre SU MISMO ICONO con Internet.
   Vuelve a la pantalla de destinos. No borres ni reinstales el icono y no
   borres los datos de Safari: así conservas su almacenamiento actual.
7. Mantén pulsado el nombre de Sky Explorer en la pantalla de destinos durante
   aproximadamente un segundo → Buscar actualización → Cerrar. Espera.
   Cuando aparezca Actualización lista · Guardar y recargar, tócalo.
8. Espera a que la aplicación recargue y muestre Disponible sin conexión ·
   Tierra y Luna. Mantén pulsado otra vez el nombre para comprobar:
   Versión: 4.1.1-shadow-cache
   Renderer: WebGPU, si tu iPhone lo admite.
   Ventana: PWA / pantalla de inicio, si la abriste desde el icono.
   Offline: Tierra y Luna guardadas.
   Si hay estructuras en el destino que visitaste, Sombras de construcciones
   indicará mapas reutilizados. Este dato no es una medición de FPS.
9. Entra a Tierra → Configuración → Rendimiento → Mostrar FPS. Visita la misma
   base y prueba exterior/interior, linterna y lámparas. Repite en Luna.
   Usa la misma hora y perfil al comparar y deja estabilizar el promedio.
   Esta corrección funciona en todos los perfiles, no solo en Rendimiento.
10. Para probar offline, primero confirma versión y descarga completa en la
    app instalada. Ciérrala → activa modo avión y desactiva también Wi-Fi →
    abre el mismo icono → entra a Tierra y Luna. Después restablece la conexión.

SI NO TENÍAS ICONO
Abre https://izayto.github.io/Sky-Explorer-App/ en Safari → Compartir → Añadir
 a pantalla de inicio → Añadir. Abre ese icono conectado y espera la descarga
completa allí también. La PWA y una pestaña de Safari pueden tener guardados
separados; utiliza Exportar/Importar expedición si necesitas trasladarlos.

SI SIGUE MOSTRANDO 4.1.0
No basta con que diga Disponible sin conexión: esa frase puede corresponder
al caché viejo. Comprueba la VERSIÓN en el diagnóstico.
Cierra todas las pestañas de la App y la app instalada, reabre conectado y
busca actualizaciones. Confirma también que terminó el despliegue de GitHub.
Si aún conserva la versión anterior: diagnóstico → Restablecer solo la caché
offline → cierra todas sus ventanas y la app → reabre con Internet → espera.
Ese botón borra solo archivos offline propios, no bases, inventarios ni cuaderno.
No uses Borrar historial y datos de sitios web para hacer esta actualización.
Si dice descarga pendiente, espera con Internet; no pruebes offline todavía.

SI APARECE WEBGL FALLBACK
Lee el motivo mostrado en el diagnóstico. Es el respaldo, no WebGPU.
No se ha cambiado a WebGL deliberadamente para aparentar mayor velocidad.
Si necesitas comunicar un fallo, envía versión, renderer, motivo y captura FPS.

PARA FUTURAS ACTUALIZACIONES
Sube siempre juntos todos los archivos de la entrega, incluido su worker ya
preparado. Después repite Buscar actualización → Guardar y recargar.
Conserva una copia anterior del proyecto y una exportación de tu expedición.
Si decides volver a una copia anterior, sube su conjunto coherente de archivos
y su service-worker.js; no combines shaders nuevos con worker/materiales viejos.
Los IDs de props añadidos en esta versión no existen en versiones anteriores:
exporta la expedición antes de cualquier vuelta atrás para conservarla.
